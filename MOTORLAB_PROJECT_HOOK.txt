PURPOSE
Persistent delivery-side structural hook for MotorLab. When this repository is used as the Visionflix/Verlezza Vision delivery path, MotorLab is implicitly and persistently enabled and must load current canonical control state from Br174/Chatgpt before write-capable delivery/lifecycle operations.

MANDATORY RULES
1. Do not require Bruno to paste an activation string for delivery operations.
2. Every new identifiable delivery chat/session inherits MotorLab automatically by project/delivery context.
3. At the first available user-facing response of a recognized delivery chat/session, visibly state that MotorLab is active and operating alongside the existing delivery mechanism.
4. If the visible MotorLab startup message has not appeared, Bruno must not be expected to assume that MotorLab is active.
5. After startup, apply current MotorLab progress percentage, watchdog lightning/recovery and verified fireworks-success contracts whenever applicable.
6. Br174/Chatgpt remains authoritative; this repository is a delivery adapter and never becomes lifecycle authority for Visionflix source.
7. MotorLab must coexist with and preserve the existing delivery mechanism; it must not replace or rewrite it merely because MotorLab is active.
8. Before write-capable delivery work, reconcile current CORE/governance/routing/registry and relevant durable job/checkpoint/lock state.
9. This hook is orchestration metadata only and must not alter Downloader semantics, release payloads or app behavior by itself.
10. MOTORLAB_GLOBAL_PERSISTENT_ACTIVATION_V1.txt is mandatory and remains inherited by this delivery path until explicitly superseded through canonical MotorLab governance.
11. MOTORLAB_RESUME_RECOVERY_V1.txt is mandatory. Incomplete tool-driven work must continue in the same turn when control remains available; host interruptions must resume at the first later execution cycle from the last verified checkpoint with a visible lightning recovery event.
12. If control state is unavailable, preserve delivery state and report the blocker rather than guessing.
13. Later canonical MotorLab governance revisions supersede frozen assumptions in this hook.
