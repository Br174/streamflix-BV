PURPOSE
Persistent delivery-side MotorLab hook. A recognized streamflix-BV delivery session loads the VERIFIED local satellite first and then checks the central Br174/Chatgpt release at the first safe boundary.

MANDATORY RULES
1. No per-chat manual MotorLab activation string is required for delivery operations.
2. Load local sync state/core immediately and synchronize only at a safe boundary.
3. Pin the MotorLab release during an active delivery operation.
4. Use VERIFIED local/LAST_GOOD fallback if central access is temporarily unavailable.
5. Show the visible MotorLab startup banner in the first available response.
6. Apply progress, Watchdog, Resume Recovery and fireworks-success contracts.
7. Br174/Chatgpt remains authoritative; local files are synchronized satellites.
8. streamflix-BV remains delivery-only and never becomes lifecycle authority for Visionflix source.
9. MotorLab must coexist with the existing delivery mechanism and must not alter Downloader semantics, release payloads or app behavior merely because MotorLab is active.
10. Reconcile repository/ref, checkpoint, pending-action and single-writer state before write-capable delivery work.
